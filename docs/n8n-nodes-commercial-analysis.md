# Комерційний аналіз n8n Community Nodes

> Базуючись на ресьорчі від 06.06.2026
> Фокус: які ноди варто робити на продаж

---

## Методологія оцінки

Кожен node оцінюється за 4 критеріями (1-5):
- **🥊 Конкуренція** — наскільки зайнята ніша
- **💰 Монетизація** — готовність платити
- **📈 Об'єм ринку** — скільки потенційних юзерів
- **🔧 Складність** — скільки роботи (5 = легко, 1 = складно)

---

## 1. 📊 PPTX Generation — ⭐ ПРІОРИТЕТ #1

| Критерій | Оцінка | Чому |
|----------|:---:|------|
| 🥊 Конкуренція | 5 | **Нуль конкуренції.** Єдина "обгортка" — `pptxgenjs` в Code node, але це не node |
| 💰 Монетизація | 4 | B2B кейс: звіти, презентації, сертифікати. Компанії платять за ready-made |
| 📈 Об'єм ринку | 5 | Універсальна потреба — від маркетингу до HR, sales, education |
| 🔧 Складність | 3 | Середня. Ядро — `pptxgenjs` (вже є). Основна робота: шаблони, UI для n8n |

**Бізнес-модель:**
- Freemium: базові шаблони безкоштовно
- Pro $9/mo: кастомні шаблони, brand kits, змінні `{{placeholder}}`, bulk export
- Аудиторія: будь-який n8n юзер який генерує документи

**MVP за 2 тижні:**
- Input: JSON масив слайдів
- Шаблони: титульний, текст, bullet list, image, chart
- Output: binary PPTX / base64 / URL
- Placeholders: `{{company}}`, `{{date}}`, etc.

## 2. 🏪 OLX.ua — ⭐ ПРІОРИТЕТ #2

| Критерій | Оцінка | Чому |
|----------|:---:|------|
| 🥊 Конкуренція | 5 | **Немає нічого.** OLX не має API для продавців, тільки партнерський |
| 💰 Монетизація | 5 | Селлери платять за автоматизацію. OLX Pro-package вже $15-30/mo |
| 📈 Об'єм ринку | 3 | Тільки Україна, але 500K+ активних продавців |
| 🔧 Складність | 2 | Складно. Потребує Puppeteer + анти-бан захист. Нема офіційного API |

**Бізнес-модель:**
- Paid-only $19/mo
- Функції: автопостинг оголошень, бустінг, відповіді на повідомлення, аналітика
- Аудиторія: OLX power-sellers (100+ оголошень), dropshippers

**MVP за 4 тижні:**
- Публікація оголошень (Puppeteer-based)
- Оновлення цін/залишків
- Автовідповіді на повідомлення
- Статистика переглядів

⚠️ **Ризик:** OLX може забанити IP/акаунт за автоматизацію через браузер

| 📈 Об'єм ринку | 3 | ~100K українських продавців на Prom |
| 🔧 Складність | 4 | Легко. XML API вже є. Потрібен тільки node wrapper |

**Бізнес-модель:**
- Freemium: базові операції (get products, orders)
- Pro $9/mo: авто-публікація, масовий імпорт, синхронізація з обліковою системою

**MVP за 1 тиждень:**
- CRUD товарів
- Отримання/оновлення замовлень
- Клієнти
- Імпорт цін з XLSX/CSV

## 🎯 Фінальна стратегія

### План А: "Ukrainian E-commerce Suite" (найвищий ROI)

Пакет з 3 нод:
```
n8n-nodes-ukr-ecommerce
├── @ukr-ecommerce/olx     — автопостинг, відповіді, аналітика
├── @ukr-ecommerce/prom     — товари, замовлення, клієнти
└── @ukr-ecommerce/nova     — логістика (форк/покращення існуючого)
```

**Чому це виграшно:**
- Нуль конкуренції в українському e-commerce сегменті
- Один інстал — три інтеграції
- Крос-платформні workflow: OLX замовлення → Nova відправка → Prom аналітика
- Монетизація: $29/mo за весь suite
- Цільова аудиторія: українські онлайн-магазини, дропшипери, power-sellers

**Timeline:**
| Фаза | Що | Час |
|------|-----|-----|
| 1 | Prom.ua node (XML API) | 1 тиждень |
| 2 | NovaPost node (fork + improve) | 1 тиждень |
| 3 | OLX.ua node (Puppeteer-based) | 3 тижні |
| 4 | Спільний UI, cross-node workflow | 1 тиждень |
| | **Разом** | **6 тижнів** |

---

### План Б: "PPTX Generator" (univeral SaaS)

Самостійний продукт:
- Назва: `n8n-nodes-pptx-pro`
- Ціна: $9/mo Basic, $19/mo Pro
- Ринок: глобальний, будь-який n8n юзер
- Конкуренція: нуль

**Timeline:**
| Фаза | Що | Час |
|------|-----|-----|
| 1 | Ядро на `pptxgenjs` | 1 тиждень |
| 2 | Шаблони + placeholders | 1 тиждень |
| 3 | UI полірування, документація | 3 дні |
| | **Разом** | **~2 тижні** |
